# Whisperlane v0.8.5

Whisperlane v0.8.5 fixes the engine start failure on Windows accounts whose
profile path contains non-ASCII characters, such as `Hüseyin`, `Şule`, or `ğ`.

## The bug

The engine reads its command line through the narrow ANSI path, so a model
under `C:\Users\Hüseyin\AppData\Roaming\...` reached the engine as
`C:\Users\H?seyin\AppData\Roaming\...`. The model could not be opened, and both
the Vulkan and processor starts failed with:

```
0xC0000409
```

The engine log often contained no stderr at all, which made the failure look
like a missing runtime or a driver problem.

## The fix

- The app now passes the Windows 8.3 short path for the model and uses the
  same short path as the engine's working directory.
- The short name resolves to the same file. Nothing is copied and no extra
  disk space is used.
- The engine's own path handling is unchanged; the app gives it an ASCII path
  at the launch boundary.
- ASCII profile paths behave exactly as before.

This also explains why the same installer worked on machines with an ASCII
user name and failed on `Hüseyin`; the runtime package was never the problem.

## Notes

- The fix uses Windows 8.3 short names, which are enabled by default on the
  system volume. If 8.3 name creation has been disabled on the profile volume,
  the app keeps the long path and the failure can remain; a copied ASCII
  staging path is the follow-up.
- Includes the 0.8.4 runtime cleanup and the 0.8.3 self-contained runtime
  work.

## If you are on 0.8.4

Update to 0.8.5 if your Windows user name or profile path contains non-ASCII
characters. Users with an ASCII profile path do not need this update for the
engine to start, but it is the current release.

## Packaging and verification

- Installers: NSIS setup and MSI for Windows 10/11 x64.
- Verify the download against `SHA256SUMS.txt`:

  ```powershell
  Get-FileHash Whisperlane_0.8.5_x64-setup.exe -Algorithm SHA256
  ```

- The installer itself is not Authenticode-signed, so Windows SmartScreen may
  ask for confirmation. The updater artifact is signed and verified by the app.
