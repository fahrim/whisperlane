# Whisperlane v0.8.6

Whisperlane v0.8.6 adds a second local speech engine and the first multilingual
model it carries: Qwen3-ASR 0.6B. The Whisper models, the default, and every
existing flow are unchanged.

## The new choice

Settings -> Speech model now offers **Qwen3-ASR 0.6B (multilingual)**, an
811 MB download that reads 31 languages, including Turkish, English, Chinese,
Cantonese, Japanese, Korean and Arabic.

- It runs on its own engine, built from transcribe.cpp with the Vulkan backend
  and a processor fallback, shipped beside the Whisper engine in the installer.
- The model downloads only when the user asks, like the others. The file is
  checked against the SHA-256 its catalog pins before it is accepted.
- Each engine family keeps its own runtime version and pointer, so upgrading
  one never disturbs the other.

## What it is and is not

- It is a multilingual option. The reference project's evaluations put
  Qwen3-ASR ahead mainly on Chinese and Cantonese; on Turkish the default
  Whisper model measured better in a development spot check. Nothing here
  claims otherwise.
- The first take after the app launches this engine pays a one-time pipeline
  warm (about 3.8 seconds on the development machine). Later takes are fast:
  about 0.1 to 0.2 seconds for clips of 4 to 11 seconds.
- Both engines can invent closing phrases on audio that is only silence or
  noise. A take that never rises above the capture's silence floor is still
  rejected before an engine is asked.
- The weights are Apache-2.0 and are never bundled. Their licence and the
  conversion notice are recorded in `THIRD_PARTY_NOTICES.md`.

## If you are upgrading from 0.8.5

- The installer carries two engine pairs. The app installs each into its own
  versioned directory under `%APPDATA%`; your existing Whisper model, settings,
  and shortcuts are untouched.
- The new engine is used only when the Qwen model is selected. Choosing any
  Whisper model behaves exactly as before.
- The engine log records which family and pin served a take, for support.

## Packaging and verification

- Installers: NSIS setup and MSI for Windows 10/11 x64.
- Verify the download against `SHA256SUMS.txt`:

  ```powershell
  Get-FileHash Whisperlane_0.8.6_x64-setup.exe -Algorithm SHA256
  ```

- The installer itself is not Authenticode-signed, so Windows SmartScreen may
  ask for confirmation. The updater artifact is signed and verified by the app.
